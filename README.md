## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería en Sistemas Computacionales** y desarrollador interesado en crear soluciones prácticas mediante tecnologías web, aplicaciones de escritorio y servicios backend.

Me gusta transformar ideas en proyectos funcionales, aprender nuevas herramientas y fortalecer continuamente mis conocimientos en programación, arquitectura de software, bases de datos y desarrollo de interfaces.

Actualmente enfoco mi aprendizaje y práctica en:

- Desarrollo backend con **Java y Spring**.
- Desarrollo frontend con **JavaScript, TypeScript y Angular**.
- Aplicaciones web con **PHP y Python**.
- Programación concurrente y aplicaciones Java de escritorio.
- Diseño de interfaces y experiencias web interactivas.
- Persistencia de datos y consumo de servicios.

## 🛠️ Cómo instalar o consultar este repositorio

Este repositorio funciona como un **README de perfil de GitHub**, no como una aplicación ejecutable independiente. Para consultarlo o personalizarlo:

### Clonar el repositorio

```bash
git clone https://github.com/MarioSi3ri/MarioSi3ri.git
cd MarioSi3ri
```

### Visualizar el contenido

Abre el archivo `README.md` con cualquier editor de texto o Markdown. También puedes visualizarlo directamente desde la página principal de mi perfil de GitHub.

### Personalizar el perfil

1. Edita `README.md`.
2. Actualiza la información personal, tecnologías y proyectos.
3. Comprueba que los enlaces y las imágenes funcionen.
4. Guarda los cambios y publícalos en la rama `main`:

```bash
git add README.md
git commit -m "actualizar README de perfil"
git push origin main
```
